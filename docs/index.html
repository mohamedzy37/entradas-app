EntradasYa

Aplicación web de venta de entradas · Proyecto educativo

Proyecto educativo

EntradasYa es una práctica de la asignatura Puesta en Producción Segura (curso 2026-27). No es un servicio comercial: no se venden entradas reales ni se realizan cobros.

Qué es

Una aplicación web distribuida para consultar eventos (museos, fútbol, cine, festivales, conciertos) y reservar entradas de demostración. Tiene backend (FastAPI) y frontend (React) separados, tres roles de usuario (administrador, gestor y cliente) y autenticación con JWT.

Inicio de sesión con Google

Puedes registrarte con correo y contraseña o iniciar sesión con tu cuenta de Google. En ese caso, la aplicación solo recibe tu nombre, tu dirección de correo y un identificador de cuenta. Consulta la política de privacidad para más detalles.
